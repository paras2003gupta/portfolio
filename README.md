# Paras Gupta — Portfolio Website

A production-grade, interactive portfolio built with pure HTML, CSS & JavaScript. No frameworks, no build step — deploy instantly.

## 🚀 Deploy to Vercel (2 minutes)

### Option A — Vercel Dashboard (Recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repo
4. Click **Deploy** — done!

### Option B — Vercel CLI
```bash
npm i -g vercel
vercel --prod
```

## ✨ Features
- Custom animated cursor
- Particle network background (canvas)
- Scroll-reveal animations
- Animated skill progress bars
- Subtle glitch effect on hero name
- Fully responsive (mobile, tablet, desktop)
- Dark fintech aesthetic with cyan & lime accents
- Zero dependencies, zero build step

## 🎨 Customization
All content lives in `index.html`. To update:
- **Colors** → edit CSS variables in `:root` (top of `<style>`)
- **Content** → find the relevant `<section>` and update the text
- **Links** → update GitHub/LinkedIn/email href values
